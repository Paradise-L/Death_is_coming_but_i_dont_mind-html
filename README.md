# Death_is_coming_but_i_dont_mind-html
Смерть приближается, но я и не против

HTML5, ([github-pages](https://paradise-l.github.io/Death_is_coming_but_i_dont_mind-html/)), визуальная новелла, мой первый проект, фулл-стек.


## навигация

-главное меню - "index.html"

-диалоги игры записаны в - "dialogues.json"

-логика и синтаксис диалогов прописан в "dialogues_guide.txt"

-скрипт соединяющий "index.html" и "dialogues.json" это "script.js"

-спрайты и фоны в "sprites/" и "bg/" соответственно
