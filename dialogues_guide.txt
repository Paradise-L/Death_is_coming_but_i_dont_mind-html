диалог:

type - тип (диалог/выбор/fade-in/fade-out)

name - имя автора реплики
name_color- цвет имени
say - реплика

background - путь к фону вида "url('bg/bg.png')", если не нужно менять фон то заполнять необязательно

sprite - путь к спрайту вида "sprites/firstCharacter.png", если не нужно менять спрайт то заполнять необязательно
spriteSize - размер спрайта, исходный - 100
spriteX - положение спрайта на сцене по оси X
spriteY - положение спрайта на сцене по оси Y
spriteBrightness - яркость спрайта, исходная - 100

jump - после этого диалога будет скачок на сцену указанную в значении
jumpBack - какая сцена была до этого
jumpBackLen - сколько было диалогов в той сцене

change - меняет один lp, (пишется название лп)
changeOperation - либо = либо +
changeValue - количество начисляемого лп


выбор:

type - тип (диалог/выбор/fade-in/fade-out)
numberOfOptions - колво опций (например 2)
option_n - текст опции n 
option_n_result - какие lp изменяет опция n
option_n_result_value - какое количество lp изменяет опция n


fade-in: Переписываешь прошлую строчку но в type пишешь fade-in
fade-out: Пишешь диалог но в type пишешь fade-out
